About Bluetooth call audio

DuoLink mirrors call state and controls, but Android only lets the default dialer own call audio. To hear the call on your PC, pair the phone to Windows via Bluetooth (Hands-Free Profile) — then Windows routes call audio to the PC speakers/mic.

Use in Zoom / Teams / Meet / OBS

1. Add this stream in OBS: Sources → + → Media Source → Local File off → Input URL below.
2. Start OBS Virtual Camera, then select it as the camera in your meeting app.

There is no bundled Windows camera driver: DuoLink streams MJPEG over your LAN, and OBS Virtual Camera is the supported bridge into meeting apps. The URL includes a session token that refreshes each time you press the copy button.

App Intro

DuoLink is a powerful local Wi-Fi solution that bridges your Windows PC and Android device into one unified ecosystem. Experience seamless two-way control, file sharing, screen mirroring, and communication without relying on cloud services.

App Features & Purpose

  • Secure local pairing with TLS public-key pinning
  • Use Phone as Remote (trackpad, keyboard, media controls)
  • Control Phone: screen mirroring with accessibility control
  • Android notifications mirroring with inline replies
  • SMS messaging from Windows
  • Phone calls management from PC
  • Phone media browser with preview & transfer
  • Use Android phone as Windows webcam
  • Device status & diagnostics
  • Two-way file transfer up to 100MB
  • Clipboard synchronization
  • Chat between devices

Purpose: To eliminate the gap between your phone and PC by providing secure, fast, and local connectivity for productivity, control, and seamless workflow integration.
